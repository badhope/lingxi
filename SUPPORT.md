### 🐛 Reporting Issues

When reporting an issue, please include:

- **Operating System**: Windows, macOS, Linux
- **Python Version**: `python --version`
- **DATA-Agent Version**: Check `requirements.txt`
- **Error Message**: Complete error traceback
- **Steps to Reproduce**: How to reproduce the issue
- **Expected vs Actual**: What you expected vs what happened

### 📚 FAQ

**Q: How do I get an API key?**
A: Visit the OpenAI website to create an API key.

**Q: Is DATA-Agent free to use?**
A: DATA-Agent is open source under MIT license. You only pay for API usage.

**Q: Can I use other LLM providers?**
A: Yes! DATA-Agent supports OpenAI, Anthropic, Azure OpenAI, and more.

**Q: How do I deploy DATA-Agent?**
A: See the deployment section in [README.md](./README.md).

**Q: Can I contribute to the project?**
A: Absolutely! See [CONTRIBUTING.md](./CONTRIBUTING.md) to get started.
