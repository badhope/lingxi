# Support

## Where to ask

- Bug / feature: GitHub Issues
- Security: see [SECURITY.md](./SECURITY.md)
- General questions: GitHub Discussions if enabled, otherwise Issues

## When filing an issue, include

- OS, Python version (`python --version`)
- Commit / version
- The exact command or request that broke
- Full traceback, not a screenshot of the last line

## Self-help

- [README.md](./README.md) — what runs and how
- [dataagent/config.py](./dataagent/config.py) — every env var the app reads
- `python main.py` then open `http://localhost:8000/docs` for the live API
